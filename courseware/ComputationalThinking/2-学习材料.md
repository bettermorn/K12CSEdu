## 高一 L2　谁先谁后，谁能同时

**学习目标**：会画任务依赖图，区分必须顺序做的和可以并行做的任务。

**概念卡　串行与并行**
- **串行**：B 必须等 A 做完才能开始（A→B）。
- **并行**：A 和 B 互不依赖，可以同时做。
- **关键路径**：从开始到结束，用时最长的那条串行链，它决定了总工期。

**例题**　科技节任务及用时（天）如下，求最短总工期。

| 编号 | 任务 | 前置 | 用时 |
|---|---|---|---|
| A | 确定时间和场地 | 无 | 1 |
| B | 设计活动项目 | A | 2 |
| C | 制作海报 | B | 2 |
| D | 准备器材 | B | 3 |
| E | 安排工作人员 | B | 1 |
| F | 布置场地 | A | 1 |
| G | 现场活动 | C、D、E、F | 1 |

**解答思路**　画箭头：A→B→(C、D、E)→G，A→F→G。
- 路径 A→B→C→G = 1+2+2+1 = 6
- 路径 A→B→D→G = 1+2+3+1 = **7**（最长）
- 路径 A→B→E→G = 1+2+1+1 = 5
- 路径 A→F→G = 1+1+1 = 3

最短总工期 7 天，关键路径是 A→B→D→G。想缩短工期，就要在 D（准备器材）上想办法。

**任务**
1. ★ 在上表中，哪些任务可以并行？
2. ★★ 如果"准备器材"可以拆成"采购"（2 天）和"调试"（1 天，须在采购后），总工期会变吗？
3. ★★★ 为"周末家庭大扫除"自己列出不少于 7 个任务，画依赖图并求最短总工期。

**课后微训练**　泡茶：烧水 8 分钟，洗杯子 2 分钟，取茶叶 1 分钟，泡茶 1 分钟（须水开、杯净、茶叶就位）。最少多少分钟？（提示：烧水时同时做另外两件事。）

## 高一 L5　数列里的秘密

**学习目标**：从数据中发现规律，并用语言和公式表达。

**概念卡　模式识别**
发现反复出现的规律、趋势和共同点，并把规律推广到类似问题。

**例题**　观察数列 2, 5, 10, 17, 26, __，下一项是多少？写出第 n 项。

**解答思路**
1. 求相邻两项的差：3, 5, 7, 9；
2. 差依次增加 2，所以下一个差是 11；
3. 下一项 = 26 + 11 = **37**；
4. 另一个角度：2 = 1²+1，5 = 2²+1，10 = 3²+1，所以 aₙ = n² + 1。验证 n = 6：36+1 = 37。✓

> 小提示：找规律有两条常用路线——**看差**（相邻项如何变化）和**看形**（每项与它的序号有什么关系）。

**任务**

2. ★★ 求 1, 4, 9, 16 … 和 2, 6, 12, 20 … 的通项。

## 高一 L7　重复的事交给循环

**学习目标**：用"如果……那么……"（条件）和"重复……直到……"（循环）描述规则。

**概念卡**
- **条件**：如果 成绩 ≥ 60 ，那么 记为及格，否则 记为不及格；
- **循环**：对每一名学生，重复同样的判断；
- **计数器**：先设为 0，每符合一次加 1。

**例题**　5 名学生成绩：55, 60, 72, 48, 90，数一数有多少人及格。

**伪代码**
```text
及格人数 = 0
依次读取每名学生的成绩：
    如果 成绩 >= 60：
        及格人数 = 及格人数 + 1
输出 及格人数
```
**结果**：60、72、90 及格，共 3 人。

**Python 版（选做）**
```python
scores = [55, 60, 72, 48, 90]
count = 0
for s in scores:
    if s >= 60:
        count += 1
print(count)   # 3
```

**任务**
1. ★ 用伪代码求"优秀（≥85）的人数"。
2. ★★ 同时输出最高分和最低分（提示：先用第一个成绩当作初始的最高分）。
3. ★★★ 把分数换成"每日步数"，求步数达标（≥8000）的天数，说明哪些地方没变，哪些变了。

## 高一 L9　哪些信息才有用

**学习目标**：区分关键信息和无关细节，理解"满足功能即可，不收集无关信息"。

## 高一 L14　找得更快：顺序与二分

**学习目标**：比较顺序查找和二分查找，理解"有序"才能折半。

**例题**　有序数据：3, 8, 12, 17, 25, 31, 46, 52, 68，查找 46。

- **顺序查找**：从头逐个比较，46 在第 7 位，要比较 7 次；最多（查 68 或查不到）要 9 次。
- **二分查找**：
  1. 9 个数，中间是第 5 个 25；46 > 25，丢掉左半，剩 31, 46, 52, 68；
  2. 取中间附近，如 46（或 52）；若是 52，46 < 52，剩 31, 46；
  3. 比较 46，找到。

**为什么要有序？**　只有数据有序，比较目标与中间值后，才能确定目标在哪一半，并**排除另一半**。

## 高二 L12　建模与仿真

**学习目标**：只保留关键变量建立模型，并用仿真产生数据。

**例题　抛体运动仿真**
```python
import math

def trajectory(v0, angle_deg, h0=0.0, g=9.8, dt=0.05):
    a = math.radians(angle_deg)
    x, y = 0.0, h0
    vx, vy = v0 * math.cos(a), v0 * math.sin(a)
    points = []
    while y >= 0:
        points.append((round(x, 2), round(y, 2)))
        x += vx * dt
        vy -= g * dt
        y += vy * dt
    return points

pts = trajectory(10, 45)
print("落点距离约", pts[-1][0], "米")
```
**模型假设**：保留——初速度、角度、出手高度、重力；**忽略**——空气阻力、风、球的自旋。

## 高二 L13　谁更快：算法实测

**例题**
```python
import random, time

def max_loop(a):
    m = a[0]
    for x in a:
        if x > m:
            m = x
    return m

def max_sort(a):
    return sorted(a)[-1]

def run(f, a):
    t = time.perf_counter()
    f(a)
    return time.perf_counter() - t

for n in (100, 10_000, 1_000_000):
    data = [random.randint(0, 10**9) for _ in range(n)]
    print(n, round(run(max_loop, data), 6), round(run(max_sort, data), 6))
```

## 高三 L10　仿真实验

**例题　食堂排队仿真**

```python
import random

def simulate(windows, students=200, seed=1):
    random.seed(seed)
    free_at = [0] * windows            # 每个窗口什么时候空闲（秒）
    t = 0
    total_wait = 0
    for _ in range(students):
        t += random.randint(0, 6)                  # 下一个学生到达（间隔 0~6 秒）
        k = free_at.index(min(free_at))            # 去最早空闲的窗口
        start = max(t, free_at[k])
        total_wait += start - t                    # 等待时间
        free_at[k] = start + random.randint(10, 30)  # 服务时间 10~30 秒
    return total_wait / students

for w in range(4, 11):
    print(w, "个窗口，平均等待", round(simulate(w), 1), "秒")
```

## 高三 L13　确定还是随机

**概念卡**
- **确定性算法**：同样的输入，每次得到同样的结果与过程；
- **随机（概率）算法**：用随机数，结果可能每次略有不同，但统计上有规律。

**例题　蒙特卡洛法估算 π**
```python
import random

def estimate_pi(n):
    inside = 0
    for _ in range(n):
        x, y = random.random(), random.random()
        if x * x + y * y <= 1:
            inside += 1
    return 4 * inside / n

for n in (100, 10_000, 1_000_000):
    print(n, estimate_pi(n))
```
**观察**：点越多，估计越接近 3.14159…，但每次运行不完全一样。

### E.2 Python 与 C++ 写法对照

| 想做的事 | Python | C++ |
|---|---|---|
| 变量 | `x = 5` | `int x = 5;` |
| 小数 | `y = 3.5` | `double y = 3.5;` |
| 输出 | `print(x)` | `cout << x << endl;` |

### E.3 两个最容易让人误会的地方（已实测）

运行下面的程序（`scores` 的和为 326，共 5 个数）：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> scores = {55, 60, 72, 48, 91};
    int sum = 0;
    for (int s : scores) sum += s;
    cout << "sum / 个数（整数相除）: " << sum / scores.size() << endl;
    cout << "(double)sum / 个数: " << (double)sum / scores.size() << endl;
    cout << "0.1 + 0.2 == 0.3 ? " << (0.1 + 0.2 == 0.3) << endl;
    return 0;
}
```

输出：

```text
sum / 个数（整数相除）: 65
(double)sum / 个数: 65.2
0.1 + 0.2 == 0.3 ? 0
```

Python 里 `sum(scores) / len(scores)` 得到 `65.2`。

**记住：**
1. C++ 里**两个整数相除，结果仍是整数**（`7 / 2` 得 `3`）。要小数，先把其中一个转成 `double`。
2. **两种语言都不能直接用 `==` 比较小数**（`0.1 + 0.2 == 0.3` 结果为假）。应该判断两数之差是否足够小。

## 附录 F　读报错（Python 与 C++ 通用）

> 学会读报错是最划算的调试技能。**只读第一条**：哪一行、什么类型的问题、编译器或解释器的建议是什么。下表为在 Python 3.13 与 Apple clang 21 上得到的真实报错，你的环境措辞可能略有不同。

### F.1 C++ 编译时报错

| 你写的错误 | 报错信息 | 怎么改 |
|---|---|---|
| 少了分号 | `expected ';' at end of declaration` | 看提示的那一行（或上一行）末尾 |
| 变量名拼错 | `use of undeclared identifier 'totl'; did you mean 'total'?` | 按“did you mean”修改 |
| 类型不匹配 | `cannot initialize a variable of type 'int' with an lvalue of type 'const char[4]'` | 检查变量类型与赋的值 |
| 函数参数个数不对 | `no matching function for call to 'add'` | 对照函数定义的参数 |
| 变量没赋初值（需 `-Wall`） | `variable 's' is uninitialized when used here` | 声明时赋初值，如 `int s = 0;` |

### F.2 Python 运行时报错

| 你写的错误 | 报错信息 | 怎么改 |
|---|---|---|
| 下标越界 | `IndexError: list index out of range` | 检查下标范围和循环终点 |
| 除以零 | `ZeroDivisionError: division by zero` | 除之前先判断分母 |
| 变量没定义 | `NameError: name 'total' is not defined` | 检查拼写，或是否先赋值 |
| 字符串和数字相加 | `TypeError: can only concatenate str (not "int") to str` | 用 `str()` 或 `int()` 转换 |
| 无法转成数字 | `ValueError: invalid literal for int() with base 10: 'abc'` | 先检查输入内容 |
| 缩进不对 | `IndentationError: expected an indented block after 'if' statement on line 1` | 条件后的语句要缩进 |
| 冒号漏了 | `SyntaxError: expected ':'` | `if / for / while / def` 行末加冒号 |

### F.3 “没有报错”不等于“对了”

C++ 里下面这类错误**不会让程序停下**：

- `vector` 用 `[]` 读取越界位置：程序照样运行，结果不可信（用 `.at()` 才会抛出异常）；
- 整数除以零：结果依平台而定，本机实测不报错；
- 小数除以零：得到 `inf` 或 `nan`。

所以：**用测试用例证明程序对，而不是用“没报错”证明。**
