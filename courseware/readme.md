# 学习目标
学习将训练学生的设计思维Design thinking、产品思维、软件开发能力和AI应用能力。

# 学习注意事项

1. 不要用 **应试思维** 参与本项目学习。参考 [大一学生摒弃应试思维个人自评问卷：基于工程教育认证标准的学习方式诊断表](https://mp.weixin.qq.com/s/1ikVrJ1WUmJOeOv1_9n3yQ)，调整学习方法。

2. 学习过程中不要满足于做 **算法调包** 大侠，要理解不同算法模型的本质，以掌握解决复杂问题的方法。

3. 在学习中要掌握产品设计和实现方法，不要只满足于几个算法几行代码。可参考 [为什么要做科技产品而不是项目？](https://www.bilibili.com/video/BV12H4y1S7s8/)

4. 项目管理  [用GitHub做敏捷开发项目管理
](https://github.com/bettermorn/ACMWDevHubPPT/wiki/%E7%94%A8GitHub%E5%81%9A%E6%95%8F%E6%8D%B7%E5%BC%80%E5%8F%91%E9%A1%B9%E7%9B%AE%E7%AE%A1%E7%90%86)

5. 学习需要阅读参考书籍
