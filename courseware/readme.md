软件产品设计课程说明

# 学习目标
学习将训练学生的设计思维Design thinking、产品思维、软件开发能力和AI应用能力。设计思维强调团队协作和多元背景。

# 学习注意事项

1. 不要用 **应试思维** 参与本项目学习。参考 [大一学生摒弃应试思维个人自评问卷：基于工程教育认证标准的学习方式诊断表](https://mp.weixin.qq.com/s/1ikVrJ1WUmJOeOv1_9n3yQ)，调整学习方法。本项目强调Learning by Doing，需要学习者**同步解决一个身边的实际问题**。学习成果可以做成一个 **Portfolio（作品集）** 。包括你观察到了什么（Empathize）、你定义了什么问题（Define）、你想出了什么疯狂的点子（Ideate）、你做了什么低成本的模型（Prototype）和用户反馈如何，你如何改进（Test）。

2. 学习过程中不要满足于做 **算法调包** 大侠，要理解不同算法模型的本质，以掌握解决复杂问题的方法。

3. 在学习中要掌握产品设计和实现方法，不要只满足于几个算法几行代码。可参考 [为什么要做科技产品而不是项目？](https://www.bilibili.com/video/BV12H4y1S7s8/)

4. 项目管理  [用GitHub做敏捷开发项目管理
](https://github.com/bettermorn/ACMWDevHubPPT/wiki/%E7%94%A8GitHub%E5%81%9A%E6%95%8F%E6%8D%B7%E5%BC%80%E5%8F%91%E9%A1%B9%E7%9B%AE%E7%AE%A1%E7%90%86)

5. 学习需要阅读参考书籍。
6. 寻找伙伴。高中生和2-3个不同性格、不同学科优势的团队伙伴一起学习和做项目，效果会翻倍。

# 参考书籍
1. Design Thinking: A Guide to Innovation  1.详解设计思维6步骤，包括“观察与反思”。2.分享真实学生团队项目故事，激发解决社会问题的创新意识。3.获美国NSTA/CBC“最佳STEM图书”等多个奖项及星级评论。

2. Sprint 中文版《设计冲刺：谷歌风投如何5天完成产品迭代》（第2版） ，内容很故事化，像读一本创业小说。
